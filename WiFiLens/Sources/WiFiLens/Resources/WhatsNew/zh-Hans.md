# 1.6.0 更新内容

WiFi Lens 1.6.0 面向 OSS 与 Pro 扩展了实时 Wi-Fi 工作区，带来 AP 雷达、组件化的频谱工作区和全新的聚合热力图；Pro 继续将实时诊断连接到历史、报告与分析。

## 主要更新

### AP 雷达（预览）

* 选择一个接入点，在移动过程中跟踪它的接收信号强度。
* 查看信号是在变强、变弱还是保持稳定；目标暂时消失时，会明确显示信号丢失状态。
* 可选的脉冲声音会随信号强度变化；声音控制和脉冲预设可在设置中调整。
* AP 雷达提供基于 RSSI 的参考，不会判断接入点的精确方向或距离。

### 组件化的频谱工作区

* 频谱面板现在采用组件化结构，每个面板都可以在频谱、趋势、表格和热力图之间切换。
* 现有的网络表格现在更容易定制：选择希望保留显示的列，只保留你关心的网络信息。
* 频段选择与各视图专属控制集中在一起，更容易按当前任务组织工作区。

### 聚合频谱热力图

* 查看 Wi-Fi 活动在频率和信号强度上的集中位置。
* 以环境整体的聚合视图进行比较，不必一次只跟踪一个接入点。
* 在支持的 2.4 GHz、5 GHz 和 6 GHz 频段之间切换查看。

### WiFi Lens Pro

* Timeline 现在可以导出匿名化 Markdown 报告，并提供更完整的本地化事件详情。
* Statistics 和 Insights 提供了更清晰的本地化操作与反馈入口。
* Pro 将实时观测与录制、事件历史、重复模式分析、菜单栏访问和扩展导出工作流连接起来。

## 稳定性、本地化与辅助功能

* 热力图在可用时使用硬件加速；不支持时也会安全地切换到备用计算方式。
* 改善并发更新、扫描结果变化和稀疏信道规划下的渲染稳定性。
* 扩展了 AP 雷达和新频谱工作区的本地化与辅助功能支持。

## Edition 提供范围

组件化的频谱工作区、聚合热力图、AP 雷达预览，以及核心实时 Wi-Fi 分析能力，OSS 与 Pro 均可使用。

WiFi Lens Pro 额外提供录制、Timeline 历史、Statistics、Insights、菜单栏访问和扩展导出工作流，适合长期观察与分析。
