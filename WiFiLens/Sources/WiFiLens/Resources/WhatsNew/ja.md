# 1.6.0 の更新内容

WiFi Lens 1.6.0 では、OSS と Pro のライブ Wi-Fi ワークスペースを AP Radar、コンポーネント化されたスペクトラムワークスペース、新しい集約ヒートマップで拡張しました。Pro では、ライブ診断から履歴、レポート、分析へとつながるワークフローをさらに進めています。

## 主な変更

### AP Radar（プレビュー）

* アクセスポイントを選択し、移動しながら受信信号強度を追跡できます。
* 信号が強くなっているか、弱くなっているか、安定しているかを確認できます。対象が見えなくなった場合は、信号ロスト状態を明確に表示します。
* オプションのパルス音は信号強度に応じて変化します。サウンド設定とパルスプリセットは設定から変更できます。
* AP Radar は RSSI に基づく目安を提供します。アクセスポイントの正確な方向や距離を判定するものではありません。

### コンポーネント化されたスペクトラムワークスペース

* スペクトラムパネルがコンポーネント化され、各パネルでスペクトラム、トレンド、テーブル、ヒートマップを切り替えられます。
* 既存のネットワークテーブルをより柔軟に使えるようになりました。重要なネットワーク情報と一緒に表示する列を選択できます。
* 帯域選択と表示ごとの操作をまとめて配置し、目的に合わせてワークスペースを組み立てやすくしました。

### スペクトラムの集約ヒートマップ

* 周波数と信号強度のどこに Wi-Fi アクティビティが集中しているかを確認できます。
* 1 台のアクセスポイントを追いかけるのではなく、現在の環境全体を集約して比較できます。
* 対応している 2.4 GHz、5 GHz、6 GHz 帯域を切り替えて表示できます。

### WiFi Lens Pro

* Timeline から匿名化された Markdown レポートを出力でき、イベント詳細のローカライズも強化しました。
* Statistics と Insights に、より分かりやすいローカライズ済みアクションとフィードバック入口を追加しました。
* Pro ではライブ観測と録画、イベント履歴、繰り返しパターンの分析、メニューバーアクセス、拡張されたエクスポートをつなげて利用できます。

## 安定性、ローカライズ、アクセシビリティ

* ヒートマップは利用可能な場合にハードウェアアクセラレーションを使用し、利用できない場合も安全に代替処理へ切り替わります。
* 同時更新、スキャン結果の変化、チャネルプランの空きがある場合の描画安定性を改善しました。
* AP Radar と新しいスペクトラムワークスペースのローカライズおよびアクセシビリティ対応を拡充しました。

## エディションごとの提供内容

コンポーネント化されたスペクトラムワークスペース、集約ヒートマップ、AP Radar プレビュー、基本的なライブ Wi-Fi 分析は OSS と Pro の両方で利用できます。

WiFi Lens Pro では、録画、Timeline 履歴、Statistics、Insights、メニューバーアクセス、拡張されたエクスポート機能を利用でき、長期的な観測と分析に対応します。
